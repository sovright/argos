# Pre-NU7 SQLite migration fixture

`pre-nu7.sqlite` is an empty wallet database generated by the SDK versions in
Argos's pre-upgrade lockfile (PR #290), not by the NU7 SDK under test:

- `zcash_client_backend 0.24.0-rc.4`
- `zcash_client_sqlite 0.22.0-rc.4`
- `zcash_primitives 0.30.0`, `zcash_protocol 0.10.1`
- Rust 1.88 (fixture generation only; the NU7 project uses Rust 1.89)

The seed is public synthetic **64 bytes of `0x42`**, with one testnet account
named `pre-NU7 public fixture`, birthday 4,465,025 and recorded tip 4,465,025.
The prior chain state uses empty commitment trees and an all-zero block hash;
this is a schema/account fixture, not chain evidence. It contains no received
notes, UTXOs, transactions or funds, and no network requests are made.

Retained fixture SHA-256:

```
51bce8f9dc545187702cf1b4bb5e32277a18a0182002836c53fdb289ed7df328
```

It has 57 rows in `schemer_migrations`; `PRAGMA integrity_check` returns `ok`.
The generator's lockfile is retained. Account UUIDs and creation timestamps
are intentionally not deterministic, so regenerated SQLite bytes will have a
different checksum while preserving the same semantic fixture. Never replace
this fixture with a database produced by the SDK being tested.

From the repository root, write a new output path (the generator refuses to
overwrite an existing database):

```sh
RUSTC_WRAPPER='' CARGO_INCREMENTAL=0 RUSTFLAGS='' \
  CARGO_TARGET_DIR=/private/tmp/argos-merge-target \
  cargo +1.88 run --offline --manifest-path tests/regtest/legacy-wallet-db/Cargo.toml \
  -- /private/tmp/argos-legacy-wallet-new.sqlite
```

The old fixture generator deliberately uses its own target, outside the NU7
build lane. Disabling the compiler wrapper avoided a local stalled sccache
server; no production project setting was changed.

`pre_nu7_database_migrates_without_losing_account_or_scan_work` copies this
fixture to a temporary directory, runs the new SDK initializer, checks account
identity and scan work, advances the recorded tip across NU7, checks SQLite
integrity, then closes and opens it again. The retained fixture is never
migrated in place.
